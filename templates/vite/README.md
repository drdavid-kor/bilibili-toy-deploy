# Vite Toy starter · Vite Toy 起点

Run `npm ci && npm run build`; upload `dist/`. `vite.config.js` sets `base: './'` so generated assets work under the Toy subdirectory.

Replace the original geometric `toy-assets/poster.png` and `toy-assets/icon.png` with artwork for your project before release. Keep the paths in `toy.config.json` current.

运行 `npm ci && npm run build`，上传 `dist/`。修改 `src/main.js`、`src/style.css`、`toy.config.json` 后即可创作自己的内容。登录凭据只放在 GitHub Secret 中。

发布前请把 `toy-assets/` 中的几何占位图换成自己作品的封面和图标，并核对配置路径。

See the main repository's quick start for the GitHub workflow and authentication steps.
