# HTML Toy starter · HTML Toy 起点

Edit `site/index.html`, `site/assets/style.css`, and `site/assets/main.js`. The publishable directory is `site/`; it has no build step. Open `site/index.html` locally to try it.

Replace the original geometric `toy-assets/poster.png` and `toy-assets/icon.png` with artwork for your project before release. Keep the paths in `toy.config.json` current.

编辑 `site/` 里的页面、样式与交互脚本。上传目录是 `site/`，无需构建。请修改 `toy.config.json` 中的 slug 和标题，凭据只放在 GitHub Secret 中。

发布前请把 `toy-assets/` 中的几何占位图换成自己作品的封面和图标，并核对配置路径。

This starter uses relative asset paths. See the main repository's quick start for the GitHub workflow and authentication steps.
