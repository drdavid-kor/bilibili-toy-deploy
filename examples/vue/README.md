# Vue + Vite Toy example · Vue + Vite Toy 示例

Run `npm ci && npm run build` to create `dist/`. The example uses `#en` and `#zh` as working hash routes. In a real app, adapt existing routes without removing features; history routes that rely on server rewrites need separate review.

运行 `npm ci && npm run build` 生成 `dist/`。示例使用可工作的 `#en` 和 `#zh` 路由，Vite 的 `base: './'` 使资源在 Toy 子目录中保持相对路径。
